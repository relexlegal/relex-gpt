# Positioning — Relex × GPT

**Relex doesn't replace ChatGPT. It helps you use ChatGPT end-to-end.**

Lawyers already use ChatGPT and Codex. What stops them from using those models
for *real* client work is confidential client data, firm know-how, client
communication, payments, and finding the next client. Relex handles that layer.

- **Protect PII and know-how** — sealed client-side; model never receives plaintext PII.
- **Automate customer service** — guest links and case agents.
- **Handle payments for free** — browser billing only.
- **Open a new market** — be reachable through Relex.

Safety is cryptographic + API-enforced, not a policy the model must remember.
